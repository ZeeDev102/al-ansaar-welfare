# Al Ansaar Welfare Trust website

## Upload and publish
1. Extract the ZIP on your computer.
2. Open your al-ansaar-welfare GitHub repository.
3. Choose Add file > Upload files.
4. Upload index.html, style.css, script.js and the entire assets folder to the repository root. Do not upload the ZIP itself.
5. Commit changes.
6. Go to Settings > Pages. Select Deploy from a branch, main, / (root), then Save.
7. Wait for GitHub to finish publishing; the live link appears on the Pages settings screen.

Keep index.html at the repository root, not inside another folder.
No paid hosting, Vercel setup, dependencies or build command are required.

Edit index.html to change text, style.css to change appearance and script.js for navigation behaviour.
All supplied photos are in assets/ as optimized WebP files, with full-image layouts.
